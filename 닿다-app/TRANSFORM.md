# 만나 → 닿다 탈바꿈 진행 상황

만나(SELAH/MANNA 공유 엔진)를 닿다로 탈바꿈 중. 토대는 그대로 재사용, 향하는 곳만 사랑앓이로.

## 재사용하는 토대 (그대로 살림)
- Next.js 15 · React 19 · TypeScript · Tailwind
- Supabase (로그인·DB) · Anthropic Claude (대화 엔진)
- PWA(앱 설치)·푸시 알림·다국어(ko/en/th/es/pt/hi/zh)
- **위기 카드**(자해·위기 감지 → 도움 연결) = 닿다 AI 안전망 그대로
- 카톡 스크린샷 분석(상대 대화 읽기) = 닿다 "그 사람 마음 이해"에 직결
- 감정 기억(memory)·이모션 감지

## 바꾼 것
