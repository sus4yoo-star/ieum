# 경쟁사 분석 — 출결버스 (CHULGYEOL BUS)

정리: 2026-06-19 · 출처: 오프라인 브로슈어 3단 리플릿 (사진 `출결버스-브로슈어/01~03.jpeg`)

## 한 줄 콘셉트
> "학원관리는 출결버스 — 스마트한 학원 운영을 도와줍니다." / **초기 도입비용 ZERO**

도입 문의: 1601-4810

## 핵심 기능 3대 축

| 영역 | 세부 기능 |
|------|-----------|
| **① 실시간 출결** | 실시간 출결 체크, 출결 메시지 자동 발송, 출결 현황 리포트, 기간별 출석 분석 통계 |
| **② 결제/정산** | 수강료 자동 결제, 정기/회차 청구방식, 한눈에 보는 미납관리, 확실하고 빠른 정산관리 |
| **③ 학원 관리** | 단체 문자 발송, 학원 공지사항 발송, 개인별 상담 이력, 학생별 심층 관리, 상담일지 작성 |

## 마케팅 포인트
- 초기비용 ZERO (전용 PC만 있으면 도입)
- 서비스 오류 ZERO
- 복지 가득 자사몰 지원
- 메시지 맞춤 설정 / 다양한 메시지 형식
- 1:1 무료 도입 상담(STEP 1~3), 무료체험 제공

## 이음 관점 시사점 (빈자리 = 우리 기회)
- **학원 전용 화이트라벨**: 출결버스는 공용 솔루션 톤. 이음은 "우리 학원 전용 앱" 포지셔닝으로 차별화.
- **AI 차별화**: 출결버스에 없는 AI 상담 자동응대 / AI 리포트 = 이음 2~3차 업셀 무기.
- **초단순 UX**: "원장은 버튼만" 원칙으로 기능 나열형 경쟁사 대비 단순함 강조.
- **채널 신뢰 이전**: 출결버스는 전화 영업 중심(1601-4810). 이음은 서점·총판 소개(리퍼럴)로 신뢰 이전 + CAC 절감.
- 주의: 출결버스의 "초기비용 ZERO"는 이음의 "셋업비 면제·평생 고정"과 정면 경쟁 메시지. 가격 정직성 게이트 유지.
