## 2. 설치 (원장님 폰에)

앱은 웹 주소만 있으면 됩니다. 설치 파일 없음.
1. 원장님 폰 브라우저로 앱 주소 열기 (배포 후 `ieum.theamov.com/app` 형태 예정)
2. **홈 화면에 추가** (아이폰: 공유 → 홈 화면에 추가 / 안드로이드: 메뉴 → 홈 화면에 추가)
3. 이제 앱 아이콘처럼 켜집니다.

## 3. 하루 운영 흐름 (원장님)

1. **등원 시간** — ‘출결’ 탭에서 온 학생 **[등원]** 탭 → 뜨는 문구를 **[문구 복사]** → 학부모 카톡방에 붙여넣기 (또는 [문자 앱으로 보내기])
2. **하원 시간** — 같은 학생 **[하원]** → 같은 방식
3. **공지 있을 때** — ‘공지’ 탭 → 템플릿 누르거나 직접 입력 → 전체 발송
4. **월초 수납** — ‘수납’ 탭 → 미납 학생 **[안내]** → 입금 확인되면 **[완료]**(영수증 문구 자동)

> 핵심: 원장은 **버튼 누르고 → 복사 → 카톡 붙여넣기**. 명단·계산·문구는 앱이 다 함.
